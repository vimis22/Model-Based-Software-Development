# Model-Based-Software-Development

## Introduction
This Project is a part of a 10 ECTS course in Model-Based Software Development.
The objective with this project is to implement a Domain Specific Language for Tables, especially in LaTeX.

## Problem Specification
One of the main problems of creating a Table in Latex, is that the table lacks structure.
Due to the lack of structure, the developers are not able to easily read or implement a Table in Latex.
Therefore the objective of this project is to create a DSL, where like PlantUML it becomes easier for developers and other users to create Tables in Latex as an extension.

### Process
During the Development Process, we will start out with the Scoping of the Project with Metamodeling, where Structure and Implementation will take place afterwards.
In the end, each contributing group member will create an Individual Extension as Validation, which adds an extra feature to the DSL on their behalf.
